# OpenCraw release status

OpenCraw currently retains no release, publication, signing, packaging, native
application, or artifact-promotion workflow. The only retained GitHub Actions
workflows are **Docs** and **OpenCraw CI**.

Inherited OpenClaw release procedures are not current OpenCraw operating
instructions. They remain available from upstream documentation and immutable
Git history when compatibility research requires them.

A future OpenCraw release or publication process requires a separate U/D
directive, explicit scope, security review, retained-workflow decision, and
validated repository record. This page does not define a branch, promotion, or
publication mechanism.

See [OpenCraw GitHub Actions policy](/reference/github-actions-policy) and
[OpenCraw validation infrastructure](/development/opencraw-validation).
