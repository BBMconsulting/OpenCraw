# Mantis Slack desktop runbook

This inherited runbook is inactive in OpenCraw. The fork retains no Slack
desktop proof workflow and ships no external desktop worker provider. The
compatibility adapter fails closed before a lease, SSH process, or external
desktop command can start.

Do not use the historical commands, provider settings, or workflow names as
current OpenCraw instructions. Historical evidence remains available through
Git history when upstream compatibility research requires it.

Current testing and runner policy is documented in
[OpenCraw validation infrastructure](/development/opencraw-validation) and
[OpenCraw GitHub Actions policy](/reference/github-actions-policy).
